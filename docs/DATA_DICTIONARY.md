## Raw Data Files

### Adjacency Matrices

**Location:** `data/interim/extracted/Data/3.AdjacencyMatrices/`

**Filename Pattern:** `Adj_Matrix_{Sex}_ICD_age_{age_num}.csv`

**Format:** Space-separated matrix, N×N dimensions where N = number of ICD codes

**Description:** Symmetric adjacency matrix representing comorbidity relationships between diseases. Entry (i,j) represents the association strength between disease i and disease j.

**Example:** `Adj_Matrix_Female_ICD_age_5.csv` - Female patients, age 40-49

---

### Prevalence Data

**Location:** `data/interim/extracted/Data/1.Prevalence/Prevalence_Sex_Age_Year_ICD.csv`

**Columns:**
- `sex`: Patient sex (Female/Male)
- `Age_Group`: Age range string (e.g., "0-9", "10-19", ..., "70-79")
- `year`: Year of observation (1997-2014)
- `icd_code`: ICD-10 diagnosis code
- `p`: Prevalence (proportion of population with this diagnosis)

**Description:** Disease prevalence stratified by sex, age group, and year.

---

### ICD Code Mappings

**Location:** `data/interim/extracted/Data/ICD10_Diagnoses_All.csv`

**Columns:**
- `diagnose_id`: Numeric ID (1-indexed) corresponding to adjacency matrix position
- `icd_code`: ICD-10 diagnosis code
- `descr`: German description of diagnosis

**English Version:** `ICD10_Diagnoses_All_ENG.csv`
- `Code`: ICD-10 diagnosis code
- `ShortDescription`: English description of diagnosis

---

### Mortality Data

**Location:** `data/interim/mortality/`

**Files:**
- `mortality_diag_female.csv` - Female mortality data
- `mortality_diag_male.csv` - Male mortality data

**Columns:**
- `icd_code`: ICD-10 diagnosis code
- `age_10`: Age group ID (1-8)
- `mortality`: In-hospital mortality rate (proportion, 0-1)

**Description:** In-hospital mortality rates for each diagnosis, stratified by age group.

## Analysis Output Columns

### Outlier Detection Output

**File:** `data/processed/outliers_data_S1.csv`

| Column | Type | Description | Calculation |
|--------|------|-------------|-------------|
| `Ratio` | float | Degree-to-prevalence ratio | degree / prevalence |
| `Log_ratio` | float | Log10 of ratio | log10(degree / prevalence) |
| `Deviation` | float | Modified z-score | 0.6745 × (x - median) / MAD |
| `Outlier` | boolean | Is outlier flag | Log_ratio < 20th or > 80th percentile |
| `outlier_type` | string | Type of outlier | "high_degree" or "low_degree" |
| `age_num` | int | Age group ID | 1-8 |
| `type_order` | int | Sorting order | 0=high_degree, 1=low_degree |

**Interpretation:**
- `Log_ratio > 0`: Disease is more connected than expected from prevalence
- `Log_ratio < 0`: Disease is less connected than expected from prevalence
- `Deviation > 3.5`: Strong outlier (rule of thumb)

---

### High-Mortality Sinks Output

**File:** `data/processed/high_mortality_sinks_ZSCORE.csv`

| Column | Type | Description | Calculation |
|--------|------|-------------|-------------|
| `z_betweenness` | float | Z-score of betweenness | (x - mean) / std |
| `z_mortality` | float | Z-score of mortality | (x - mean) / std |
| `z_product` | float | Product of z-scores | z_betweenness × z_mortality |
| `z_geom_mean` | float | Geometric mean | √(z_betweenness × z_mortality) |

**Interpretation:**
- Both z-scores must be positive (above average in both dimensions)
- `z_product` used for selection (top 20%)
- `z_geom_mean` used for ranking/reporting
- Higher values indicate more critical nodes

---

### Bridge Edges Output

**File:** `data/processed/bridge_edges_mortality_ZSCORE.csv`

| Column | Type | Description | Calculation |
|--------|------|-------------|-------------|
| `z_betweenness` | float | Z-score of edge betweenness | (x - mean) / std |
| `z_mort_diff` | float | Z-score of mortality difference | (x - mean) / std |
| `z_product` | float | Product of z-scores | z_betweenness × z_mort_diff |

**Selection criteria:**
- Both z-scores > 0
- `z_product` >= top 5% threshold
- `Mortality_Diff` >= 0.30 (30%)

---

### Critical Nodes Intersection Output

## Network Metrics

### Node-Level Metrics

| Metric | Symbol | Description | Range | Interpretation |
|--------|--------|-------------|-------|----------------|
| **Degree** | k | Number of connections | 0 to N-1 | Higher = more comorbidities |
| **Betweenness Centrality** | BC | Fraction of shortest paths through node | 0-1 (normalized) | Higher = more central, bridge-like |
| **Closeness Centrality** | CC | Average distance to all other nodes | 0-1 | Higher = more accessible |

---

### Graph-Level Metrics

| Metric | Description | Range | Interpretation |
|--------|-------------|-------|----------------|
| **Connected Nodes** | Nodes with degree > 0 | 0 to N | Excludes isolated diseases |
| **Average Degree** | Mean connections per node | 0 to N-1 | Network density indicator |
| **Average Path Length** | Mean shortest path | ≥1 | Smaller = more compact network |
| **Average Betweenness** | Mean betweenness centrality | 0-1 | Centralization indicator |
| **Average Closeness** | Mean closeness centrality | 0-1 | Accessibility indicator |
| **Modularity** | Community structure strength | -0.5 to 1 | Higher = stronger communities |
| **Clustering Coefficient** | Local connectivity density | 0-1 | Higher = more triangles |

## Statistical Measures

### Z-Score (Standard)

**Formula:** `z = (x - μ) / σ`

**Where:**
- x = individual value
- μ = mean
- σ = standard deviation

**Interpretation:**
- z > 0: Above average
- z < 0: Below average
- |z| > 2: Unusual (95% threshold)
- |z| > 3: Very unusual (99.7% threshold)

---

### Modified Z-Score

**Formula:** `M = 0.6745 × (x - median) / MAD`

**Where:**
- MAD = Median Absolute Deviation = median(|x - median|)
- 0.6745 = 75th percentile of standard normal distribution

**Advantages:**
- More robust to outliers than standard z-score
- Uses median instead of mean
- Uses MAD instead of standard deviation

**Interpretation:**
- |M| > 3.5: Potential outlier (rule of thumb)

---

### Log-Ratio

**Formula:** `log_ratio = log₁₀(degree / prevalence)`

**Interpretation:**
- log_ratio = 0: Degree proportional to prevalence
- log_ratio > 0: More connected than expected
- log_ratio < 0: Less connected than expected
- log_ratio = 1: 10× more connected than expected
- log_ratio = -1: 10× less connected than expected

**Why log10?**
- Handles wide range of ratios (0.01 to 100+)
- Symmetry: log₁₀(10) = 1, log₁₀(0.1) = -1
- Easy interpretation in orders of magnitude

## Data Quality Notes

### Missing Values

- **Prevalence = 0**: Excluded from degree-prevalence analysis (log undefined)
- **Mortality missing**: Treated as 0 in z-score calculations
- **Isolated nodes**: Filtered out (degree = 0) for most analyses

### Data Range Validation

Expected ranges for quality checks:

| Variable | Expected Range | Concern if outside |
|----------|---------------|-------------------|
| Prevalence | 0.0001 - 0.5 | >0.5: Data error |
| Mortality | 0 - 0.5 | >0.5: Check calculation |
| Degree | 0 - 200 | >200: Unusual, verify |
| Betweenness | 0 - 0.3 | >0.3: Highly central node |
